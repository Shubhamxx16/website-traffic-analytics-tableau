# Data dictionary: website_analytics.csv

10,000 rows, 15 columns, UTF-8 CSV.

| Column | Description |
|---|---|
| Date | Date of the visit (YYYY-MM-DD), 2024-07-16 to 2024-10-14 |
| Traffic Source | Organic, Direct, Paid or Referral |
| New vs Returning Visitors | New or Returning |
| Device Type | Mobile, Desktop or Tablet |
| Browser Type | Chrome, Safari, Firefox, Internet Explorer or Edge |
| Operating System | Android, iOS, Windows, macOS or Linux |
| Geographic Data - Country | Indian state or union territory (35 values; the column name says "Country") |
| Landing Page | Homepage, Product Page, Blog, Contact Us or Checkout |
| Exit Page | Homepage, Product Page, Blog, Contact Us or Checkout |
| Campaign | Spring Sale, Holiday Discounts, Product Launch or Newsletter |
| Page Views | Number of pages viewed (0 to 15) |
| Sessions | Number of sessions (0 to 12) |
| Bounce | Yes or No |
| Avg. Session Duration | Average session duration, values from 1.0 to 10.0 (unit not stated in the source) |
| Converted | Yes or No |
